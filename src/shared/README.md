# src/shared — 최하단 레이어

모든 레이어가 여는 유일한 폴더. 그래서 여기 들어오는 것에는 다른 곳보다 엄한
기준이 붙는다.

## 여기 두는 것

**순수 계약**만 둔다 — 라우트 경로, 스토리지 키, 열거 값, 그리고 그것들을 다루는
순수 함수. 입력만 보고 출력이 정해지고, 바깥 세계(네트워크·파일·전역 상태)를
건드리지 않는 코드다.

## 여기 두지 않는 것

lint가 강제하는 것들이라, 어기면 `pnpm lint`에서 막힌다:

| 금지                     | 이유                                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| import (앱 안팎 전부)    | 여기 의존이 하나 생기면 그 패키지가 앱의 **모든** 청크에 실린다                              |
| `.tsx` (컴포넌트)        | shared는 순수 계약이다. 공유 컴포넌트는 `src/components/`                                    |
| 재수출 (`export … from`) | shared가 다른 모듈의 2차 문이 되면 경계 검사가 shared까지만 보고 끝난다                      |
| 모듈 최상위 문           | 어디서나 import되는 모듈이라 부수효과가 생기면 모든 청크에 함께 실린다 (`'use client'` 포함) |

같은 폴더 안의 파일끼리 import하는 것은 허용된다 — 그건 이 레이어 내부의 일이다.

## 왜 최하단인가

의존 방향이 한쪽으로만 흐르게 하려면 아무것도 import하지 않는 바닥이 하나
있어야 한다. 그 바닥이 있으면 "이 상수는 어디서 왔나"를 추적하다 순환에 빠지는
일이 없다. 규칙 전체는 `eslint.config.mts`의 boundaries 블록에 있다.
